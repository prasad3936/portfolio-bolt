# CV File Instructions

To enable the CV download functionality, please add your CV file to this directory with the name:
`Prasad_Zungare_CV.pdf`

The download button in the Hero section will automatically link to this file.

## Alternative Options:

1. **Host on Google Drive or Dropbox**: Upload your CV and use a direct download link
2. **Use a different filename**: Update the filename in `src/components/Hero.tsx` line 11
3. **External hosting**: Host the CV on your own server or cloud storage

Make sure the CV file is accessible and the path matches the one specified in the Hero component.
